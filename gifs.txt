# IMPORTANT: use the DIRECT image URL, not the Giphy page URL. Slack renders the
# gif from the image URL itself, so a page link shows up as a broken image.

#   good:  https://media.giphy.com/media/<id>/giphy.gif
#   bad:   https://giphy.com/gifs/some-slug-<id>

# To get the direct URL on giphy.com: open the gif → "Share" → "Copy GIF link",
# or right-click the gif → "Copy Image Address".

# the post simply goes out without a gif.
